## FULL STACK DEVELOPER (JavaScript/Firebase)

### TASK:

* The task is to create a simple web messaging application.
* The main interface must display a list of all registered users, and next to each user there should be an option to start a conversation.
* By clicking the conversation option, a window opens showing the history of all previous messages and an option to send a new message.
* Next to the conversation option, create a bar chart showing the number of messages exchanged between the two users in the last 24 hours, summarized by hour.

### Additional Requirements:

* Ensure message confidentiality, meaning a user can only see messages they sent or received.
* Messages must arrive in real time, without refreshing the page.
* Implement new user registration.
* Implement login and logout for existing users.

### BONUS points:

* Use Firebase services to build the application (Hosting, RTDB, Auth, etc.).
* The chart updates in real time.
* Intuitive application design (UI/UX).and
* Innovation (implementation of additional functionality not explicitly required).
